# PDS 原生工程与多格式文件提交规范

扩展名不是允许/禁止名单。先保存厂商原包唯一原件与哈希（本地非公开），工作副本保留原目录跑通；匹配 MINI 修订、完整器件、顶层、工具/IP、启用约束。
第一次复现不同时换板、升级IP、整理文件名、优化RTL。路径整理另开PR并重新构建。

可能必要的输入包括 .pds、Verilog/SystemVerilog/头文件、VHDL、.fdc等约束、.idf等实际IP配置、
生成RTL/网表/仿真模型、文件清单/Tcl、.hex/.mem初始化、固件/模型。只有真实项目读取后才能填入正式清单。
每个工程的 JSON 登记必须能定位所有必需输入。当前检查器只验证清单及路径，不声称解析原生 .pds 或理解加密IP。

## 提交什么

- 模块变化：模块及实际工程引用；IP变化：参数和必要配套；时钟变化：相关约束；固件变化：源码到镜像的完整链。
- 自动生成不等于可删。另一位成员在全新检出目录按固定工具成功再生成前，许可允许的必要生成输入保留。
- 不能整体忽略 ip/、sim/、build/、pnr/、rev_1/ 或所有 .idf/.fdc/.hex/.mem。
- 厂商非UTF-8、加密和二进制不统一转码，不用自动选择 ours/theirs 掩盖冲突。
- 公共工程/IP/约束编辑前协调；冲突不透明时从正确配置重生成并核对工具真实加载内容。
- 源码不每次打ZIP替代Git差异；完整ZIP仅是固定版本的派生产物。
- 大波形、权重、视频、原包先核实合法存储方案，不擅开付费LFS。登记可获取地址、版本、哈希和访问条件。
- 根 LICENSE 不自动覆盖第三方源码、IP、模型或数据；许可不明不公开。

## 新目录复现

另一成员按受测SHA新检出，合法取得依赖，不复制旧缓存/输出。检查器通过后，按任务执行打开、仿真、综合、实现、人工上板的适用层级。
记录工具/IP、种子/参数、完整输入、约束覆盖、报告和实际下载文件哈希。位流每次字节相同不是唯一复现定义。
没有真实菜单/脚本验证前不提供“通用PDS一键命令”。当前无团队工程可执行。
