# 每层证明什么

| 层级 | 必须保留 | 不能推导 |
| --- | --- | --- |
| 文档/清单 | 路径、来源、问题与两人审核 | 工程可综合 |
| 独立仿真 | 输入/种子、正常边界错误复位、完整日志/波形 | 上板工作 |
| PDS | 真实入口、工具IP、初始化、资源/约束/时序 | 真实识别和动作 |
| 板级 | 人工安全确认、下载文件哈希、实物现象 | 完整系统验收 |
| 联调 | 真正工程引用/实例、时钟复位CDC、地址IRQ、驱动、数据版本 | 所有异常覆盖 |
| 整机 | 当前工件真实图像、设备内AI、动作出口反馈、日志恢复、盲测 | 任意工业现场认证 |

正常件、定义缺陷、未知/无效图、重复旧判定、出口无反馈/卡高、取消/换件/模式切换、存储满/写失败、急停/重上电均须有适用用例。
模拟判定只验机构，最终AI构建禁止默认使用替身。软件golden与RTL须独立核对。
