# 最终设备要做什么

对象：低压、断电的接线组件装配，推荐检查 2P/3P 端子、带键连接器、螺钉头等四类部件；四类部件不等于四种缺陷。
样件型号、尺寸、可见方向、容差需实物试验批准。不是通用 PCB 检测、通电功能测试或工业认证。

## 两种完整模式

托盘：人工放件 → 安全条件与摆放有效 → 完整帧 → 设备内推理与规则 → 当前件显示/保存 → 拿走换件重新建身份。
停车式传送：单件进入 → 到位停车并停稳 → 有效完整帧 → 设备内推理/规则 → 导向/放行 → 真实出口反馈 → 保存处理结果。
主机须独立启动，传送模块拆开后托盘仍完整工作。不能用托盘永久替代传送。

PASS 有充分合格证据；FAIL 有充分不合格证据；REVIEW 是证据不足/矛盾；INVALID 是画面等输入无效，FAULT 是设备故障。
未知、遮挡、矛盾、超时、没有出口反馈均不能自动 PASS。命令已发不是分流已完成；旧电平和计时也不是本次出口证据。

## 推荐路线，尚未冻结或实现

VexRiscv 派生五级 RV32IM，必要 Cache/动态预测/异常中断；YOLOv5n v7.0、四类、320、batch1、W8A8；
CGRA4ML 派生卷积后端，补齐重排、量化、激活、残差、池化、拼接、上采样。具体参数经任务实验批准。
CPU 只做有界调度、候选/NMS、装配规则和控制，不隐藏承担硬件热路径。AXI、非缓存共享区、写完成与所有权合同必须一致。
NEureka 仅主后端正确性/PDS映射/完整链预算失败、局部修正不足时另案评估，不并行造两套整机。
不加 LLM、FPU、复杂自动上料或第二相机作为默认需求。

固定照明先成立；最多一次选择性复检，是否启用由相同独立样品上的公平实验决定。
安全禁止路径独立于 CPU 软件；人工复位、实际电气/机械验证不可用软件标志代替。
完整启动、配置校验、存储满/失败、取消/换件/模式切换/掉电恢复均属产品，不留到最后。
