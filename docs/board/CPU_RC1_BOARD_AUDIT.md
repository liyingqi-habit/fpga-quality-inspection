## 时序结论的边界

[RC1回归](../../evidence/axil-candidate-rc1-20260927.md)只证明既有27 MHz约束配置下已约束路径通过。
rstn/key/uart_rx从路径被设为false path；三项no_input_delay、四项io_min_max_delay_consistency和一项virtual_clock仍存在。不能用这一结果声称异步复位释放、CDC、按键去抖及外部接口时序全部闭合。改变输入同步/复位结构或约束后须重新冻结和回归。

## 上板准入门槛

- [ ] 核实实物版号、器件、电源铭牌/接口，保持电机和其他执行器不连接。
- [ ] 获得适用于实物的VCCIOCFG/SCBV依据；无万用表时不指导带电探针或凭其他板原理图接线。
- [ ] 在PDS实际工程设置并回读配置Bank选项，记录截图/工程版本；不得只改安装目录默认配置文件。
- [ ] 审核实际异步输入/复位路径和现有约束告警，明确哪些是设计上有依据的例外。
- [ ] 建立独立的板级验收固件：启动版本标识、UART结果、RAM/异常/IRQ测试、失败/等待状态及人工按键步骤。
- [ ] 对该固件重新跑RTL和网表、PDS并记录源/ROM/约束/位流哈希，两个非作者审核后安排人工下载。
- [ ] 现场记录冷启动、KEY0复位、串口、内存和IRQ结果；失败也保留日志，不用LED亮代替完整PASS。

当前 `program.py` 固件向RAM结果区写199字，仿真检查器负责判分并在GPIO事件后拉动key；它不是无人干预的板级验收程序，也不输出旧工程的串口PASS横幅。不可把离线ROM直接交给用户期待同样结果。

结论：**资料比对已完成一轮，物理条件核验未完成；BOARD_NOT_VALIDATED / DOWNLOAD_BLOCKED。** 这不阻止先实现和仿真板级验收固件，但不授权自动上板。
