# 取得并登记真正匹配的基础工程（T02-01）

父任务：T02；关：G0；初始可执行范围：等条件。动态负责人/状态以Issue为准，本文不宣称已认领或完成。

## 目标与边界

建立可核查的真实工程入口和依赖，不冒充已经构建。

非目标：不迁移目录、不换IP、不优化、不直接上板。

## 开始前

T01-01的板卡身份；厂商合法工程原包及获取来源。当前原包和许可未落实。

前置任务：T01-01。缺输入时只做明确可行部分，其余BLOCKED；不能凭文件存在宣布Ready。

可改：docs/setup/PROJECTS.md、docs/setup/projects.json、boards/pango_200k_mini/、evidence/。禁止顺便修改main、其他模块、未知PDS/IP/引脚；公共接口变更先协调。

## 操作

1. 根据确切MINI修订向合法来源取得原包；原件保存在仓库外，记录版本、下载来源、日期、SHA256及许可。
2. 制作工作副本，保持目录关系，人工核对入口/器件/顶层/工具与启用约束。
3. 逐项登记源/头文件/顺序/宏、IP配置与配套、初始化/固件/模型、外部依赖及合法获取方式。
4. 只在许可确认后把必需输入纳入公开范围；更新正式projects.json；按PDS_FILE_POLICY逐项确认，没有可公开工程则保持MISSING。
5. 用 python tools/project.py check 检查清单路径；另开后续子卡进行新目录构建，不能把路径通过称为PDS通过。

## 验收

- 正常：入口和全部登记输入存在且属于这版板卡。
- 边界：中文/空格路径是否被真实PDS支持另测。
- 异常：缺IP/初始化文件/外部许可时不变成READY。
- 复位/取消：本卡不下载，无硬件复位；撤销登记用新PR。

交付：真实清单、哈希、许可边界与打开工程的人工记录（若实际执行）。记录真实命令/人工步骤、版本/哈希、预期与实际、日志、未覆盖范围。未执行的测试写NOT_RUN；不把纸面评审当物理通过。

回归：运行仓库check和单元测试，复查受影响接口消费者；实际工程出现后另跑相应仿真/构建层。回退：保留上一批准版本，通过新分支PR撤销/修订，不重写main，不自动恢复危险动作。
