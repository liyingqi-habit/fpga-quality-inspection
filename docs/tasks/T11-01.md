# 定义工件到动作的身份和取消合同（T11-01）

父任务：T11；关：G5；初始可执行范围：可领取（设计）。动态负责人/状态以Issue为准，本文不宣称已认领或完成。

## 目标与边界

旧图片、旧判定、旧DMA不能作用到新工件。

非目标：不驱动电机、不用PWM或计时冒认出口成功。

S1第10章；与T06-01对齐内存所有权。

前置任务：无已完成任务要求，但必须具备上述输入。缺输入时只做明确可行部分，其余BLOCKED；不能凭文件存在宣布Ready。

可改：docs/interfaces/、docs/tasks/、evidence/。禁止顺便修改main、其他模块、未知PDS/IP/引脚；公共接口变更先协调。

## 操作

1. 定义epoch/item/frame/generation/job/decision/action关联和可信时间来源。
2. 为每个缓冲定义持有者、发布条件、释放条件；取消后须排空/隔离在途DMA。
3. 定义NOT_SENT、ISSUED、POSITION_CONFIRMED、RELEASED、OUTLET_CONFIRMED与超时/未确认/故障，写各状态证据来源。
4. 定义托盘/传送切换、换件、重启、记录满/写失败的停止接件与人工恢复流程。
5. 画出正常件、旧判定到达新件、出口卡高三条时序；提交共同合同PR。

## 验收

- 正常：动作只引用当前冻结判定。
- 边界：重复事件、序号边界、记录容量不足。
- 异常：出口卡高/无反馈不算确认。
- 复位/取消：旧DMA不污染新缓冲；重启不重放动作。

交付：身份字段、缓冲所有权、动作状态和故障时序草案。记录真实命令/人工步骤、版本/哈希、预期与实际、日志、未覆盖范围。未执行的测试写NOT_RUN；不把纸面评审当物理通过。

回归：运行仓库check和单元测试，复查受影响接口消费者；实际工程出现后另跑相应仿真/构建层。回退：保留上一批准版本，通过新分支PR撤销/修订，不重写main，不自动恢复危险动作。
