# 公共接口先约定再接线

当前没有批准版接口；T06-01、T07-01、T11-01 先形成草案，不能自行填地址、位宽、时序数字。
每份合同写：版本/批准记录、生产者/消费者、时钟与复位、合法输入、开始/保持/完成/错误/取消、资源所有权、超时、测试向量。
不兼容修改升版，列受影响模块、固件、模型包、测试及回退；消费者尚未实现也要先评审接口。

CPU/AXI：写成功退休、B应答与错误对应，MMIO不可缓存/不可投机，FENCE不能冒充缓存维护。
DMA：写应答真实完成后发布事件；禁止缓存别名；明确发布/获取、读者引用和写者独占。
追溯：item/frame/job/decision/action与epoch/generation；取消/换件/模式切换/重启隔离旧DMA，不能只丢中断。
数值：算子/形状/stride/padding/布局/位宽/累加/舍入/饱和/比例/激活与未知算子拒绝；独立golden避免共同错误。
安全：CPU失效时也能撤销执行资格；人工复位，不能用旧出口高电平作为新工件完成事件。
