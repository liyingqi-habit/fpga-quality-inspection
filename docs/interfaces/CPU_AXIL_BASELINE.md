# CPU离线集成基线 v0.1

2026-09-27：所有者已同意按32位、单时钟、单在途AXI4-Lite读写基线推进至PDS离线验收。状态：有限离线基线已实跑，PR待两名非作者审核；不是最终DDR/DMA整机ABI冻结。

完成证据：[分支/错误/取消交叉](../../evidence/cancel-branch-20260927.md)、[读写桥及机器模式](../../evidence/axil-baseline-20260927.md)、[实际集成PDS/网表](../../evidence/axil-pds-20260927.md)。旧写桥交叉、新读写桥单测和新SoC集成各有独立边界，不能相互冒充覆盖。新SoC尚未接出局部cancel，也未完成所有中断优先级/CSR边界或正式架构认证。

后续补充：[真实CPU+新AXIL取消](../../evidence/axil-cancel-20260927.md)已在专用集成测试台通过84场景及负向对照；综合SoC局部cancel仍固定0。此项不改变上述总线合同，也不宣称板级取消验证完成。

工作顺序与验收门槛：

1. 分支×错误响应×CPU复位取消：真实CPU、独立目标，验证精确异常、无年轻副作用、排空旧响应后重启；正常、负向和无响应隔离均须有证据。
2. 读写桥：AW/W独立，B完成写；AR/R完成读；32位地址/数据、4位WSTRB、2位响应、3位PROT。无burst/ID/Cache；单槽不得在旧事务未排空时复用。
3. 机器模式异常/软件、定时器和外部中断，CSR与mret；建立RV32I/M逐指令清单与独立预期，未覆盖项不能自动升级PASS。
4. 对最终实际集成版本重新综合、综合网表功能回归、PnR与时序检查。旧候选引脚、异步输入例外及零输出延迟限制必须保留，不称板级闭合。

CPU侧cmd_valid/ready表示桥接受事务。rsp_valid为单周期完成事件，error表示RESP非OKAY；读返回完整32位字，CPU负责子字选择/符号扩展，写使用CPU提供的WSTRB。CPU必须维持未接受命令有效载荷；CPU局部复位可以撤销尚未接受命令。

accepted事务即使尚未发出AW/W/AR，桥仍继续发出并等待B/R；CPU局部复位只设置cancelled并隔离CPU，旧响应排空但不回送。取消与完成同沿时取消优先；已产生目标副作用不回滚。只有bus_reset表示整个测试互连共同复位，不以它代替真实DDR排空。无响应则持续隔离，无自动超时释放。

读写地址PROT固定000（非特权、安全、数据），当前仅数据端口；不能直接冒充取指桥或具有权限隔离的总线。对于从机报告的SLVERR/DECERR（或不适用于Lite的EXOKAY），CPU一律得到error。精确异常PC/mtval由真实LSU保存，不由桥猜测。

内存和中断寄存器图必须随具体离线目标记录，不沿用为最终设备ABI。测试目标允许确定性故障注入，须明确与综合目标区分；不得将仿真外设替身称为物理DDR或中断控制器。

本轮不包含Cache/预测、DDR/DMA/多时钟、CoreMark、bitstream或上板。每一阶段完成后提交任务分支、记录实跑与限制；未完成阶段保持未完成。
