## 真实观测结果

|case|场景|原store成功退休 / trap / 年轻写接受|结论|
|---|---|---|---|
|0|AW先、最短响应|1 / 0 / 1|成功B前不退休|
|1|W先、延迟7周期|1 / 0 / 1|顺序与完成符合|
|2|同时请求、背压、延迟31周期|1 / 0 / 1|请求与响应稳定|
|3|延迟9、错误码2|0 / 1 / 0|mepc=0x80000010、mtval=0x1000000c、cause=7|
|4|延迟3、错误码3|0 / 1 / 0|mepc=0x80000010、mtval=0x10000010、cause=7|
|5|内部命令未接受时复位|1 / 0 / 1|重启后才接受首次写|
|6|AW-only复位|1 / 0 / 1|旧写排空、新CPU重启写成功；旧写未退休|
|7|W-only复位|1 / 0 / 1|同上|
|8|等待B时复位|1 / 0 / 1|同上|
|9|复位与错误B握手同沿|1 / 0 / 1|旧错误不误报新CPU，排空后重新写成功|
|10|普通成功|1 / 0 / 1|独立正常场景；真实复位后重用已在6—9验证|
|11|永久无B后局部复位|0 / 0 / 0|50周期观察中保持隔离/CPU复位，无新事务|

计数中的成功退休只指原测试store；检查器同时要求成功场景的年轻store恰好一次退休且在其B之后。6—9每例实际接受两次原地址写（复位前旧写+重启后新写），只允许新写成功退休。所有响应场景初笔B至少3周期背压。原写与年轻写落在目标不同字，避免年轻写掩盖原写内存检查。两类错误后两个字均保持模型初值。

```text
PASS: 12 real CPU scenarios and 12 trace negative controls
PASS: disabled-wait real CPU rejected: RETIRE_BEFORE_SUCCESS
PASS: 12 negative controls rejected with expected reasons
```

最后一行为原合成设施回归。12个真实轨迹负向对照均按指定原因拒绝：提前退休、错误当成功、错PC/地址/cause、年轻副作用、隔离丢失、旧退休、AW/W/B载荷变更及重用未排空槽位。

真实故障CPU本身仿真退出0且末尾值可看似正常，但独立周期检查器仍发现RETIRE_BEFORE_SUCCESS，负向入口因此判定对照成功。这说明仅凭末尾计数/内存值或SV打印PASS不足以验证写完成顺序。

## 失败与修正记录

初次Scala编译因SYNC重名失败，改为限定包名。一次生成后的WSL临时目录未保留，后续仿真因输入缺失停止，迁移到本地持久独立目录重新生成。首次全例仿真后，CSV解析遇到无异常时未初始化的CSR值X；改为仅在真实trap事件有效时输出CSR，无效周期填0，有效事件X仍拒绝。这些尝试不计通过。最终正常CPU从最终脚本重新生成，全套再次实跑。
